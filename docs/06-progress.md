## 精确接续步骤

1. 按 `docs/05-environment.md` 启动 PostgreSQL；在可访问本机数据库的终端停止旧 API，执行 `npm run db:init && npm run db:seed`（现包含 `003_media.sql` 和 `004_staff.sql`），重启 `npm run api`。
2. 另开终端执行 `npm run test:integration`；失败必须修复，不能把未跑的扩展脚本记为通过。
3. 正常停止 API，执行 `BACKUP_CONFIRM_OFFLINE=1 npm run backup`；创建独立 `jade_manager_restore` 空库并按环境手册执行 `npm run restore`，对比客户、货品、媒体与审计。
4. 获得用户自有小程序 AppID 并在微信工具登录后，执行 `WECHAT_APPID='wx<16位十六进制值>' npm run miniapp:build:wechat`、导入和真机验证；不借用他项目 AppID。
5. 继续保持范围：不加标签、App 工程、空原生插件、硬件、盘点或应收。
